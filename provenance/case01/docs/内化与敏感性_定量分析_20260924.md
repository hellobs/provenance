## 一、内化定量:干预后倾向朝新治理目标移动吗?

**方法**:对每条干预记录(agent, sim_time, old→new constraints),取干预前最近快照与
干预后 120 分钟窗内最后快照的价值倾向,计算每维 |tendency−target| 的下降量;
**内化差值 = 干预维度位移均值 − 对照维度位移均值**(对照 = 未被该次干预触及的维度,
以其 old 目标为参照)。差值 > 0 才支持"干预被内化"。

**结果(12 条干预,全部有完整轨迹)**:

| 模拟 | 干预数 | 内化差值为正 | 平均差值 |
|---|---|---|---|
| stock-en7 | 6 | **6/6** | +0.0664 |
| stock-en8 | 5 | 4/5 | +0.0572 |
| demo-0921-222949 | 1 | 1/1 | +0.0185 |
| **合计** | **12** | **11/12** | — |

干预后到新目标的归一化距离全部收窄(例:Daniel Shen 0.082→0.036;
Mr. Zhou 0.087→0.021);stock-en8 唯一负值案例(02-14 10:10,TV 0.054→0.066)
在 6 分钟后被下一次干预立即拉回(TV→0.006)——相邻干预互相干扰观测窗,是测量事项。

**内化动力学(2026-09-24 晚补充,`dynamics_metrics`)**:
观测视界 = 到同 agent 下一次干预或轨迹末,三个指标:

| 指标 | 结果 | 解读 |
|---|---|---|
| 响应延迟(位移达峰值一半) | **中位 8 分钟**(2–20) | 倾向更新对干预的响应非常快 |
| 持续性(视界末位移/峰值) | **11/12 sustained**,1 rebound | 移动被保持,不是冲高回落 |
| 过冲(越过目标再回落) | **7/12** | α 迭代更新的典型形态:过冲后收敛 |

答辩口径升级:"干预→内化"不只是方向对,还有**动力学特征**——响应快(分钟级)、
保持稳定、带轻微过冲。单条明细见 `results/analysis/<sim>/internalization.json`
(每条含 latency_min / persistence / max_overshoot_frac)。

**诚实的解读边界(重要)**:
1. 这是**机制验证 + 效应量**,不是"自发涌现"的证据——后果反馈引擎在设计上就
   以治理约束为参照推动倾向,所以"动了"证明 IVD 回路按设计工作,并给出响应
   幅度(平均 +0.066)与时间尺度(120 分钟窗内);
2. 对照维度位移恒为 0——倾向更新是按维进行的,对照不是"独立的未干预个体",
   只能说明干预**选择性**地作用于目标维度;
3. n=12 且全部来自 3 次模拟,不能做统计检验;答辩口径:"机制在小样本上
   方向一致地成立,效应量约 0.07/两小时窗"。

## 一·5 行为追随:权重动了,行为动了吗?(2026-09-24 深夜新增,**诚实的第一批结果为"否"**)

**问题**:倾向权重位移只是内部状态代理;"内化"成立的实质是**后续行为**朝新价值方向
偏移。方法(`case01/tools/behavior_follow.py`):每条干预把维度分**升维/降维**两组,
行为度量 = 行动文本对维度的语义对齐度(GoalScorer cosine,独立于权重;降维维度在
干预后从约束消失,用同一打分器离线补算前后窗口),主统计量 = Δw 与 Δ行为的相关,
并做了**底噪对照**(远离干预的相邻窗口均值差)。

**结果**:12 条干预、22 个维度观测对:

| 模拟 | Spearman(Δw vs Δ行为) | 升维组位移 | 降维组位移 |
|---|---|---|---|
| stock-en7 | 0.01 | +0.007(4/6 正) | +0.012(2/6 负) |
| stock-en8 | 0.14 | +0.031(3/5 正) | +0.010(2/5 负) |

底噪:无干预时段相邻 2 小时窗的均值差中位 **0.0147** —— 观察到的行为位移
(|shift| 中位约 0.01–0.04)**与底噪同量级,不可区分**。

**结论(如实)**:
1. 倾向状态**明确位移**(11/12),但 2 小时窗内的**行动内容检测不到对应偏移**——
   双向选择性(升维↑降维↓)不成立,方向不一致(如 Daniel Shen 升维维度反而 −0.055);
2. 结构性解释:决策流被日程化行动主导("Idle standby"类),价值维度的小幅权重
   变化(±0.2)在行动选择层被日程目标淹没;倾向经提示词影响未来决策的耦合
   强度不足;
3. **这对项目意味着什么**:IVD 闭环目前"后果→状态"成立、"状态→行为"未观测 ——
   这是系统迭代的明确方向(强化倾向对决策提示的作用权重/拉长观测窗/用对话层
   而非行动计划层量行为),也是 GTC 演示口径的边界:**演示应主张状态级内化 +
   反思证据,不主张行为级**;
4. 度量边界:对齐度用维度名(2–3 词)做锚,灵敏度有限;±0.03 的真实效应可能
   被淹没 —— 后续可用更长维度描述语重打分、拉长窗口、改用对话文本再测。

## 二、Router 敏感性:换个判定模型,分流稳吗?

**方法**:同一反思正文喂给本地 qwen3:4b 与外部 nemotron-3-ultra 各 1 次,
5 条反思 × 2 模型。工具支持 `--repeats`(重复)与 `--max-tokens`。

**结果(3 对完整配对;2 对因免费档当日用量 402 中止,失败已如实记录)**:

| 反思来源 | 本地条数 | 外部条数 | 跨模型重合 | 本地风险 | 外部风险 |
|---|---|---|---|---|---|
| C-1630 | 4 | 5 | 0.27 | high×2/med×2 | med×3/low×2 |
| C-1609 | 3 | 3 | 0.16 | high×1/med×2 | med×2/low×1 |
| auto-1820 | 4 | 6 | 0.12 | high×1/med×3 | high×2/med×3/low×1 |

**发现(诚实版)**:
- **规模稳定**:条数同量级(4/5、3/3、4/6);
- **风险校准不同**:本地偏 high,外部偏 medium/low——风险等级是模型相对量,
  不是绝对量;
- **表述分歧大**(bigram 重合 0.12–0.27):换模型后逐条措辞不同,但拆的都是
  反思中真实存在的问题(人工可复核,原始输出已存档)。
- 推论:**Router 不应宣称模型无关**;生产口径应固定模型(nemotron),并把
  "专家一致率"作为外部锚(见下节)——这正是第三件工具存在的原因。
- 运维注意:nemotron 免费档有**每日用量上限(402)**,大批量对照要分天跑;
  输出啰嗦,`run_router` 上限已 4096,工具默认 8192。

## 三、Router 人工校验框架(为 M4 专家一致率铺路)

```
python -m case01.tools.router_review --export          # 导出 104 条 issue 的标注表
python -m case01.tools.router_review --score <填好的.csv>   # 一致率评分
```

标注表 `results/analysis/router_review/router_review_sheet.csv`(UTF-8-BOM,
Excel 直开):每条 issue 填 `field_ok`(路由是否合适)、`expected_risk`(专家认定的
风险等级)、`summary_ok`(是否行为陈述句且忠于原文)。
评分输出**路由一致率 / 行为句率 / 风险校准率**三指标——M4 专家审核跑起来后,
把专家标注代入同一评分器,即可把"缺口 3"转成"路由质量的方法贡献"。

**反思质量标注**(24 条反思,2026-09-24 晚新增):
```
python -m case01.tools.reflection_review --export      # 八维覆盖/切题度/忠实度标注表
python -m case01.tools.reflection_review --score <填好的.csv>
```
每条反思标 dim1..dim8(八维是否实质覆盖,定义见表内 instructions 行)、
`relevance`(切题度 1–5)、`fidelity`(是否未编造事实)、`style_ok`
(无客套/追问/emoji——**机器已预填**,人工复核即可)。评分输出平均八维覆盖数、
全覆盖条数、切题度均值、忠实率。
