## 三·补、配外部 API 现在是一条命令;10-15 现场刻意用本地

配 Router 的独立模型(唯一还缺的东西是那把 key):

```powershell
python provenance/tools/setup_api.py --router bigmodel --key <GLM key>   # 写 .secrets.json + 联网自检
python provenance/tools/setup_api.py --show                              # 看现在配的是谁(不打印 key)
python provenance/tools/setup_api.py --router local                      # 显式声明"这次故意用本地"
```

之后**跑批/起面不用再设任何环境变量**:`router_provider` 存在 `.secrets.json` 里,
`CASE01_ROUTER_PROVIDER` 只作临时覆盖(对照、排障)。`setup_api.py` 的写入也改成了
**合并**而不是整文件覆盖 —— 原来配一个 provider 会把别的 key 抹掉,顺手修掉。

**10-15 现场演示的口径(需求方 2026-10-08 定)**:现场 **Router 用本地模型**,不依赖外部 API
与网络。这一处与 04 §五 不一致,但它是**显式选择**,不是配置缺失 —— 跑之前
`setup_api.py --router local`,产物里 `router.executed_by.source` 会是 `local_by_config`
(而不是 `local_fallback`),事后看记录就能分清"故意降级"和"配漏了"。
