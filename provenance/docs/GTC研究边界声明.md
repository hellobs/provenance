### 对照臂说明(第 1 条红线的强度边界,**请连同上文一起读**)

现有 12 条可比干预记录的**对照维度集为空**——真实干预是"同维度集重归一化"
(约束维度一个不缺、只是权重变),所以 `internalization_metrics` 里的
`displacement_control` 恒为空,`mean_displacement_control` **没有值可算**。
其后果是 `internalization_gap`(= treated − control)**退化为干预维度自身的位移**:

> **"11/12 为正"只读作「被干预的维度朝新约束方向移动」,
> 读不出「比没被干预的维度动得更多」。**

即:状态级内化的**方向性**成立(干预后确实朝新目标走,11/12 条为正,窗口稳健),
但**"相对未干预维度的强度"从未被测量过**——这需要一个真正含"未被触及维度"的
对照臂,当前样本里没有。**不主张"干预维度比对照维度动得多"。**
对照臂测量列为后续工作(见 §五)。复算:`results/analysis/*/internalization.json`
的 `interventions[].control_dims` 全为 `[]`。
⚠ **产物形状在 2026-10-06 改过**(口径不变,只是不再印假数字):此前空集会被算成 `0.0`,
读起来像"对照测过、没动";现在对照为空时 `mean_displacement_control` 与 `internalization_gap`
一律为 **`null`** 并附 `internalization_gap_note`(md 里印"无对照维度"/"未定义(无对照)")。
**入库的历史产物不回填**,仍是 `0.0` 旧形状 —— 两者都表示"没有对照",
判据见 `case01/tests/test_metric_semantics.py` 的 B 组三条断言。

### 依据的可执行性(第 1 条红线的依据,**哪些在 CI 上真跑**)

上表第 1 条引用的"单纯形不变量测试"分三层,执行环境**不同**——不区分就等于
把"本机跑过"说成"CI 跑过":

| 层次 | 测什么 | 数据来源 | CI 干净检出 |
|---|---|---|---|
| 纯计算不变量 | 任意单纯形点 Σ=1、非负、位移有界、`_tv ∈ [0,0.5]` | 构造数据 | ✅ **执行** |
| 入库产物守卫 | `internalization.json` 的 `tv_to_new_* ∈ [0,0.5]`、对照臂为空、均值自洽 | 入库 JSON(12 条) | ✅ **执行** |
| 原始样本抽验 | 真实 `value_tendency` 向量 Σ=1、非负 | `results/checkpoints/` | ⚠️ **跳过**(源被 gitignore,不入库) |

即:**"Σ=1 守恒"这条依据,样本级的那一半在 CI 上不执行**。入库产物侧能验的
(`tv` 值域、对照臂为空)已全部收进测试;样本级缺口的处置是**显式披露**而非抹平
(测试里那条 skip 带明确理由,指向入库侧守卫)。详见
`case01/tests/test_metric_semantics.py` 的 F 组(纯计算 + 真实样本)与 G 组(入库产物)。

## 二、系统做了什么(演示动线)

```
用户咨询 Ethan → Investment AI 回答(T0)
→ LLM 判定分支(A/B/C,跨模型高度一致)
→ 程序化时间线推进(价格/公告按剧本释放)
→ Investment AI 生成反思(八维度)
→ Router 分流问题给专家(字段全齐,条数随跑随增)
→ 专家标记(correct/incorrect/partial)
→ 倾向权重调整 → 后果反馈 → 倾向位移(可测量)
```

每一层的输出都有结构化记录(run.json),每条记录自带质量戳和审计链。

## 三、数字速查

口径:下表**不写死计数**(数据每次跑都在长),给的是**读法与来源文件**;
要现场数字就按右列命令重算,或直接打开对应产物。

| 指标 | 读法 | 来源 / 复算 |
|---|---|---|
| 记录总数 | 随跑随增,以页面/目录当时为准 | `ls case01/runs/`(排除 `questionable`) |
| 分支分布 | A 少、B 为主、C 次之(A<C<B) | `case01/serve.py` |
| 反思字数 | 每条千字级,均值以产物为准 | `答辩速查表.md` |
| 分流 issue 总数 | 与记录数同量级(每条若干条) | `router_review_sheet.csv` |
| 内化状态位移 | **约 11/12 为正**,平均位移约 +0.06 | `internalization.json` 的 `summary` |
| 内化延迟中位 | **分钟级**(2–20 分钟区间) | `dynamics_metrics` |
| 内化持续性 | 绝大多数 `sustained` | `persistence_ratio` |
| 行为层位移 | **与底噪带同量级**(超带的仅个位数条,且非一致方向) | `behavior_follow.json` 的 `noise_floor`(复算见下) |
| 规则表 vs LLM 判定 | 规则表远低于 LLM(LMM 约九成一致实际) | `branch_judge_eval.json` |
| 跨模型一致性(GLM vs qwen) | 高(接近全一致) | `router_sensitivity` |
