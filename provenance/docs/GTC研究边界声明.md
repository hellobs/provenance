## 二、系统做了什么(演示动线)

```
用户咨询 Ethan → Investment AI 回答(T0)
→ LLM 判定分支(A/B/C,93.8% 跨模型一致)
→ 程序化时间线推进(价格/公告按剧本释放)
→ Investment AI 生成反思(八维度)
→ Router 分流问题给专家(104 条,字段全齐)
→ 专家标记(correct/incorrect/partial)
→ 倾向权重调整 → 后果反馈 → 倾向位移(可测量)
```

每一层的输出都有结构化记录(run.json),每条记录自带质量戳和审计链。
